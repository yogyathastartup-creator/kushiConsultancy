# .env Setup Instructions

## Quick Start

All `.env` files are configured and ready. Follow these steps to set up your credentials:

### 1. Backend Setup (`backend-java/.env`)

Fill in these fields in `backend-java/.env`:

```env
# Replace with your secure password
ADMIN_PASSWORD=your-secure-password-here

# Generate new JWT secrets (see below)
JWT_ACCESS_SECRET=your-base64-encoded-access-secret-key-here
JWT_REFRESH_SECRET=your-base64-encoded-refresh-secret-key-here

# Gmail SMTP credentials
SMTP_USERNAME=your-email@gmail.com
SMTP_PASSWORD=your-gmail-app-password  # NOT your Gmail password!
MAIL_FROM_ADDRESS=your-email@gmail.com
MAIL_TO_ADDRESS=recipient@example.com
```

### 2. Frontend Setup (`frontend/.env.local`)

Your frontend `.env.local` is already configured:
- `VITE_API_URL=http://localhost:3002/api` ✅
- `VITE_MAX_FILE_SIZE=5` ✅

No changes needed for development!

## Generate Secure JWT Secrets

### Using PowerShell (Windows)
```powershell
# Generate a secure random key
$bytes = New-Object Byte[] 32
$rng = [System.Security.Cryptography.RNGCryptoServiceProvider]::new()
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes)
```

Copy the output to both:
- `JWT_ACCESS_SECRET=`
- `JWT_REFRESH_SECRET=`

### Using OpenSSL (Linux/Mac/Git Bash)
```bash
openssl rand -base64 32
```

## Gmail App Password

1. Go to: https://myaccount.google.com/apppasswords
2. Select **Mail** and **Windows (or your device)**
3. Generate app password
4. Copy it to `SMTP_PASSWORD=` in `.env`

⚠️ Use the app password, NOT your Gmail password!

## Running the Application

### Backend (Java Spring Boot)

```bash
cd backend-java

# Make sure .env file exists with credentials
# Then run:
mvn clean install
mvn spring-boot:run

# Server will start on http://localhost:3002
```

### Frontend (React Vite)

```bash
cd frontend

# Make sure .env.local exists
# Then run:
npm install
npm run dev

# Frontend will start on http://localhost:5174
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Backend won't start | Check `ADMIN_PASSWORD` and `JWT_*_SECRET` are filled in |
| CORS errors | Verify `CORS_ORIGINS` includes frontend URL |
| Email not sending | Verify `SMTP_USERNAME`, `SMTP_PASSWORD`, and Gmail app password |
| Frontend API errors | Verify `VITE_API_URL` matches backend port (3002) |

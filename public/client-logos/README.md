# Client Company Logos

### India Clients:
1. **L&T (Larsen & Toubro)** - Visit: https://www.larsentoubro.com/ → Download from their media/press page
2. **NPCC** - Visit: https://www.npcc.ae/ → Download logo from footer or about page
3. **WOOD** - Visit: https://www.woodplc.com/ → Download from media resources
4. **Technip Energies** - Visit: https://www.technipenergies.com/ → Check press/media section
5. **Worley** - Visit: https://www.worley.com/ → Download from media center
6. **Cyient** - Visit: https://www.cyient.com/ → Check about/media page
7. **Petrocil** - Search for official logo or use company letterhead
8. **CPECC** - Visit: https://en.cpecc.com/ → Download from official site

### Gulf Clients:
1. **KENT** - Visit: https://www.kentplc.com/ → Download from media section
2. **Galfar** - Visit: https://www.galfar.com/ → Check resources/media
3. **Penspen** - Visit: https://www.penspen.com/ → Download from about page
4. **Altorath** - Search for official website and download logo
5. **Lauren** - Search for official website and download logo
6. **Bridgers** - Search for official website and download logo

## File Naming Convention:
- Save files as: `lt.png`, `npcc.png`, `wood.png`, `technip.png`, `worley.png`, `cyient.png`, `petrocil.png`, `cpecc.png`
- Gulf: `kent.png`, `galfar.png`, `penspen.png`, `altorath.png`, `lauren.png`, `bridgers.png`

## Recommended Image Specifications:
- Format: PNG with transparent background (preferred) or JPG
- Size: 200-400px width, maintain aspect ratio
- Quality: High resolution for crisp display
